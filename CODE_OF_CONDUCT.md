# Code of conduct

Everyone can contribute to Omaconnect KDE Plus. Treat other contributors with respect, including people with different experience, communication styles, disabilities and access needs.

- Discuss the work and its effects. Do not attack the person.
- Give specific, useful feedback. Ask before assigning intent.
- Accept correction and respect task ownership and personal boundaries.
- Do not harass, threaten, discriminate, disclose private information or post sexual content directed at contributors.
- Keep issues and pull requests focused. Use short, clear steps where possible.

This policy covers project issues, pull requests, discussions and other spaces the maintainer operates for this project. It also applies when someone formally represents the project.

Report a concern privately to the project at **omaconnectplus@ryanw.eu**. Include enough context to explain the behavior. Do not post personal information in a public report. The maintainer will limit disclosure to what is necessary to handle the concern. If the concern involves the maintainer, use GitHub's [abuse reporting process](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam) where appropriate.

The maintainer can ask for a correction, remove content, restrict participation or ban a participant, depending on the behavior and its effects. Decisions should be proportionate and explain the relevant rule when disclosure is safe.
