# Get help

**Start with the task you are trying to complete.** You do not need a diagnosis or a proposed code fix to ask for help.

| Need | Start here |
| --- | --- |
| Use the panel or find a feature | [README](README.md), [help map](docs/HELP.md) |
| Choose or contribute an icon | [Icon sources and storage](docs/ICONS.md) |
| Install, update or recover | [Install, update and recovery](docs/INSTALL.md) |
| Understand device features and native settings | [Help map](docs/HELP.md), [KDE Connect handbook](https://docs.kde.org/stable5/en/kdeconnect/kdeconnect/) |
| Understand connection options | [Connections help](docs/HELP.md#connections) |
| Contribute or change a domain | [Contributing](CONTRIBUTING.md), [contracts](docs/CONTRACTS.md) |
| Report a security issue | [Private security report](SECURITY.md) |

For a reproducible problem, use the [bug form](https://github.com/ryan-winkler/omaconnect-kde-plus/issues/new?template=bug_report.yml). For a barrier with focus, wording, motion, contrast or cognitive load, use the [accessibility form](https://github.com/ryan-winkler/omaconnect-kde-plus/issues/new?template=accessibility.yml). For an idea or a question, use the [issue chooser](https://github.com/ryan-winkler/omaconnect-kde-plus/issues/new/choose). You can also use [Discussions](https://github.com/ryan-winkler/omaconnect-kde-plus/discussions).

State the task, expected result and observed result. Include the plugin version and whether the device is ARM or x86. A small screenshot or redacted log can help. Remove personal names, device IDs, addresses, file paths, tokens and keys before posting. Do not upload configuration directories or raw device inventories.

Native KDE Connect modules come with KDE Connect; this fork does not install extra protocol modules. Enable and configure them through the linked native settings. If a problem also occurs in the native application, record that fact so the correct project can handle it. Network presence alone does not prove a peer supports a sharing protocol.

Support is provided by volunteers as capacity allows. An open issue, an automated review or a CI pass is not a promise of a release date or hardware acceptance.
